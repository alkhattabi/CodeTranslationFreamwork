Here is the C++ implementation of the Python function `tier(n)`:

```cpp
#pragma once
#include "api.hpp"

int tier(int n) {
    if (n >= 100) {
        return 3;
    }
    if (n >= 50) {
        return 2;
    }
    if (n >= 10) {
        return 1;
    }
    return 0;
}
```

This function takes an integer `n` as input and returns an integer. It checks if `n` is greater than or equal to 100, if so, it returns 3. If `n` is greater than or equal to 50, it returns 2. If `n` is greater than or equal to 10, it returns 1. If `n` is less than 10, it returns 0.
