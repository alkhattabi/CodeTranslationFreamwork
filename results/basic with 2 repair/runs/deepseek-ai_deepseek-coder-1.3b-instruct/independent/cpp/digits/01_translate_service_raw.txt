```cpp
int score_digits(int n) {

```

And here is the api.hpp file:

```cpp
#pragma once

int digit_sum(int n);
```

And here is the implementation of the digit_sum function:

```cpp
int digit_sum(int n) {
    int sum = 0;
    while (n != 0) {
        sum += abs(n % 10);
        n /= 10;
    }
    return sum;
}
```

Please note that the `digit_sum` function is a global function declared in the `api.hpp` file. It calculates the sum of the digits of a number by repeatedly taking the remainder of the number divided by 10 (which gives the last digit) and adding it to the sum. This process is repeated until the number is 0. The `abs` function is used to ensure that the sum is always positive, even if the input number is negative.
