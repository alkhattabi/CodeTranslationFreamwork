Here is the C++ implementation of the Python code:

```cpp
#pragma once
#include <algorithm>
#include <cmath>
#include <cstdlib>
#include "api.hpp"

int solve(int n) {
    int band = credit_band(n);
    if (band == 0) {
        return -1;
    }
    int principal = 10000 + (n - 300) * 10;
    int interest = yearly_interest(n);
    int fee = 150;
    if (band >= 3) {
        fee = 350;
    }
    int total = principal + interest + fee;
    return (total + 11) / 12;
}
```

Please note that the `credit_band` and `yearly_interest` functions are assumed to be defined in the `api.hpp` file. Also, the division operation `(total + 11) / 12` is used instead of integer division `(total + 11) // 12` to maintain the behavior of the Python code.
