Here is the C++ implementation of the Python code:

```cpp
#pragma once
#include "api.hpp"

int yearly_interest(int n) {
    int band = credit_band(n);
    if (band == 0) {
        return -1;
    }
    int principal = 10000 + (n - 300) * 10;
    int rate = 18 - band * 3;
    int interest = principal * rate / 100;
    if (principal > 14000) {
        interest += 125;
    }
    return interest;
}
```

Please note that the `credit_band` function is assumed to be defined in the `api.hpp` file. The function should take an integer as input and return an integer. The function should return 0 for a credit band of 0, 1 for a credit band of 1, and so on. If the input is not a valid credit band, the function should return -1.
