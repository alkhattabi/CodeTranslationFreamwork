```java
public class Utils {
    public static int credit_band(int n) {
        if (n < 300 || n > 850) {
            return 0;
        }
        if (n >= 750) {
            return 4;
        }
        if (n >= 650) {
            return 3;
        }
        if (n >= 550) {
            return 2;
        }
        if (n >= 450) {
            return 1;
        }
        return 0;
    }
}

public class Service {
    public static int yearly_interest(int n) {
        int band = Utils.credit_band(n);
        if (band == 0) {
            return -1;
        }
        int principal = 10000 + (n - 300) * 10;
        int rate = 18 - band * 3;
        int interest = (int) (principal * rate / 100.0);
        if (principal > 14000) {
            interest += 125;
        }
        return interest;
    }
}

public class Main {
    public static int solve(int n) {
        int band = Utils.credit_band(n);
        if (band == 0) {
            return -1;
        }
        int principal = 10000 + (n - 300) * 10;
        int interest = Service.yearly_interest(n);
        int fee = 150;
        if (band >= 3) {
            fee = 350;
        }
        int total = principal + interest + fee;
        return (total + 11) / 12;
    }
}
```

This code declares public classes `Utils`, `Service`, and `Main`. The `Main` class has a public static method `solve` that uses the `Utils` and `Service` classes. The `Utils` class has public static methods `credit_band` and `yearly_interest`. The `Service` class has a public static method `yearly_interest`.
