And here is the Java version of the Utils class:

```java
public class Utils {
    public static int weight_blocks(int n) {
        if (n <= 0) {
            return 0;
        }
        if (n > 10000) {
            n = 10000;
        }
        return (n + 499) / 500;
    }
}
```

Please note that the Java version of the Utils class is in the same package as the Service class, so you can call the Utils class directly without importing it.
