```java
public class Utils {
    public static int billableUnits(int n) {
        if (n < 0) {
            return 0;
        }
        if (n > 1200) {
            return 1200;
        }
        return n;
    }
}
```

Please note that the Java version of the Utils class is not fully equivalent to the Python version because Java is statically typed and Python is dynamically typed. The Java version of the Utils class is a direct translation of the Python version, but it may not work as expected if the billable units function is not static.
