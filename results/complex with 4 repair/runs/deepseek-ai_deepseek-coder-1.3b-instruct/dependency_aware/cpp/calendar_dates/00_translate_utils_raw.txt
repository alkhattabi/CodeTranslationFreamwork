Here is the C++ implementation of the Python function `valid_date(n)`:

```cpp
#include "api.hpp"

int valid_date(int n) {
    if (n < 10000101 || n > 99991231) {
        return 0;
    }
    int year = n / 10000;
    int month = (n / 100) % 100;
    int day = n % 100;
    if (month < 1 || month > 12 || day < 1) {
        return 0;
    }
    int days = 31;
    if (month == 4 || month == 6 || month == 9 || month == 11) {
        days = 30;
    }
    if (month == 2) {
        bool leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        days = leap ? 29 : 28;
    }
    return day <= days ? 1 : 0;
}
```

This C++ function does the same thing as the Python function. It checks if the input `n` is a valid date. It first checks if `n` is within the valid range (10000101 to 99991231). Then it extracts the year, month, and day from `n`. If any of these values are not within the valid range, it returns 0. If the month is 2, it checks if the year is a leap year. If it is, it sets the number of days to 29, otherwise to 28. Finally, it checks if the day is within the valid range for the month, and returns 1 if it is, otherwise 0.
