Here is the JavaScript ES-module source code for the lodging_charge function:

```javascript
import { valid_nights } from "./utils.mjs";

export function lodging_charge(n) {
    const nights = valid_nights(n);
    if (nights === 0) {
        return 0;
    }
    const rooms = Math.floor(n / 100);
    let charge = rooms * nights * 150;
    if (nights >= 7) {
        charge -= Math.floor(charge / 10);
    }
    if (rooms >= 5) {
        charge -= Math.floor(charge / 20);
    }
    return charge;
}
```

It uses the valid_nights function from the "./utils.mjs" module. The valid_nights function checks if the input number is valid, and if it is, it returns the number of nights. If the number of nights is 0, the function returns 0. The function then calculates the charge based on the number of rooms and nights, and returns the charge. If the number of nights is 7 or more, it subtracts 10% of the charge. If the number of rooms is 5 or more, it subtracts 20% of the charge.
