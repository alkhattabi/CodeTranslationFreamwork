```javascript
import { billable_units } from "./utils.mjs";

export function energy_charge(n) {
    let units = billable_units(n);
    let charge = 0;
    if (units > 400) {
        charge += (units - 400) * 50;
        units = 400;
    }
    if (units > 200) {
        charge += (units - 200) * 30;
        units = 200;
    }
    if (units > 100) {
        charge += (units - 100) * 20;
        units = 100;
    }
    charge += units * 10;
    return charge;
}
```

This JavaScript code does the same thing as your Python code. It calculates the energy charge based on the number of billable units. The billable units are defined in the `billable_units` function. The `energy_charge` function calculates the total charge by adding the cost of each type of unit (up to 400 units) and then subtracting the rebate if the units are more than 100. The rebate is calculated as half of the charge for units over 100.
