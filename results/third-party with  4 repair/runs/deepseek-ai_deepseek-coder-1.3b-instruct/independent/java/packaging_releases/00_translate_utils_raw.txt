Here is the Java equivalent of your Python code:

```java
public class Utils {
    public static int release_rank(int n) {
        if (n < 0) {
            return -1;
        }
        int major = n / 10000;
        int minor = (n / 100) % 100;
        int patch = n % 100;
        String suffix = (patch % 4 == 0) ? "rc1" : "";
        String version = major + "." + minor + "." + patch + suffix;
        String reference = "2.1.0";
        if (new Version(version).compareTo(new Version(reference)) < 0) {
            return 1;
        } else if (new Version(version).compareTo(new Version(reference)) == 0) {
            return 2;
        } else {
            return 3;
        }
    }
}
```

Please note that Java does not have a built-in versioning system like Python's packaging.version.Version, so we use the java.util.Version class to handle versioning. The compareTo method is used to compare two versions.

Also, please note that the floor division operator (//) in Python is equivalent to the division operator (/) in Java. The modulo operator (%) is also the same in both languages.
