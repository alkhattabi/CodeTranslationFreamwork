```javascript
import { renewal_date } from "./utils.mjs";

export function grace_period(n) {
    const renewed = renewal_date(n);
    if (renewed < 0) {
        return -1;
    }
    const year = Math.floor(renewed / 10000);
    const month = Math.floor((renewed - year * 10000) / 100);
    const day = renewed - year * 10000 - month * 100;
    const due = new Date(year, month - 1, day);
    due.setMonth(due.getMonth() + 2);
    return due.getFullYear() * 10000 + due.getMonth() * 100 + due.getDate();
}
```

This JavaScript code does the same thing as your Python code. It calculates the due date for a grace period and returns it as a 3-digit integer. The `renewal_date` function is imported from the `utils.mjs` module. The `Math.floor` function is used to get the integer part of the division result, and the `Date` object is used to calculate the due date. The `setMonth` method is used to add 2 months to the due date.
