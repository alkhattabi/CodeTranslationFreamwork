Here is the C++ implementation of the Python function `release_rank`:

```cpp
#include "api.hpp"
#include <algorithm>
#include <cmath>
#include <cstdlib>

int release_rank(int n) {
    if (n < 0) {
        return -1;
    }
    int major, minor, patch;
    major = n / 10000;
    minor = (n / 100) % 100;
    patch = n % 100;
    std::string suffix = (patch % 4 == 0) ? "rc1" : "";
    std::string version = std::to_string(major) + "." + std::to_string(minor) + "." + std::to_string(patch) + suffix;
    std::string reference = "2.1.0";
    if (version < reference) {
        return 1;
    }
    if (version == reference) {
        return 2;
    }
    return 3;
}
```

This C++ function does the same thing as the Python function. It checks if the input number is negative, if it is, it returns -1. Otherwise, it extracts the major, minor, and patch versions from the input number and compares them to a reference version. If the input version is less than the reference version, it returns 1. If the input version is equal to the reference version, it returns 2. Otherwise, it returns 3.

Please note that this implementation assumes that the input number is a 4-digit number, and the reference version is "2.1.0". If these assumptions are not true, you may need to adjust the code accordingly.
