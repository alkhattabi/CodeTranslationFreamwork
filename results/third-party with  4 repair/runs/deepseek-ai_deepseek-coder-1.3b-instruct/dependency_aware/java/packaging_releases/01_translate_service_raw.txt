Here is the Java version of your Python code:

```java
public class Service {
    public static int upgrade_cost(int n) {
        int rank = Utils.release_rank(n);
        if (rank == -1) {
            return -1;
        }
        int major = n / 10000;
        int minor = (n / 100) % 100;
        int patch = n % 100;
        String suffix = (patch % 4 == 0) ? "rc1" : "";
        String version = major + "." + minor + "." + patch + suffix;
        String reference = "2.1.0";
        int penalty = 0;
        if (new Version(version).compareTo(new Version(reference)) < 0) {
            penalty = 40;
        }
        return rank * 25 + minor + patch / 5 + penalty;
    }
}
```

Please note that Java does not have a built-in version comparison library like Python, so we need to use a third-party library called `Version`. You can add it to your project by adding the following dependency to your `pom.xml` file:

```xml
<dependency>
    <groupId>com.github.dozey</groupId>
    <artifactId>version-maven-plugin</artifactId>
    <version>1.10</version>
</dependency>
```

Then run `mvn dependency:resolve` to download the library.
