Here is the Java equivalent of your Python code:

```java
import java.math.BigInteger;
import java.util.Map;
import java.util.HashMap;

public class Utils {
    public static int factor_signature(int n) {
        int value = Math.abs(n) % 1500 + 2;
        Map<BigInteger, Integer> factors = new HashMap<>();
        BigInteger i = BigInteger.valueOf(value);
        String str = i.toString();
        for (int j = 0; j < str.length(); j++) {
            char c = str.charAt(j);
            if (c != '0') {
                BigInteger factor = new BigInteger(String.valueOf(c));
                factors.put(factor, factors.getOrDefault(factor, 0) + 1);
            }
        }
        int score = 0;
        for (Map.Entry<BigInteger, Integer> entry : factors.entrySet()) {
            score += entry.getKey().intValue() * entry.getValue();
        }
        return score + 3 * factors.size();
    }
}
```

This Java code does the same thing as your Python code. It calculates the factor signature of a number, which is a sum of the product of prime factors and their exponent. The prime factors are represented as BigIntegers in Java, as Java does not have a built-in integer type that can represent arbitrarily large integers. The score is calculated as before, but the prime factors are represented as BigIntegers in the calculation.
