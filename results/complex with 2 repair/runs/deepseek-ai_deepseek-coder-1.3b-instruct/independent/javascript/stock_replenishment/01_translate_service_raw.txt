```javascript
import { weekly_demand } from "./utils.mjs";

export function order_quantity(n) {
    const demand = weekly_demand(n);
    const safety = demand < 100 ? 15 : 35;
    const available = n > 0 ? n : 0;
    const shortage = demand + safety - available;
    if (shortage <= 0) {
        return 0;
    }
    const packs = Math.floor(shortage / 12);
    return packs * 12;
}
```

This JavaScript code does the same thing as the Python code. It calculates the number of packs needed to fulfill the order quantity based on the demand and safety levels. The `weekly_demand` function is imported from the `utils.mjs` module. The `Math.floor` function is used to round down the result to the nearest whole number, as you can't order a fraction of a pack.
