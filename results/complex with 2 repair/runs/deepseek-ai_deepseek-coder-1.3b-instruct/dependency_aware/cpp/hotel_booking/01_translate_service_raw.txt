```cpp
#include "api.hpp"

int lodging_charge(int n) {
    int nights = valid_nights(n);
    if (nights == 0) {
        return 0;
    }
    int rooms = n / 100;
    int charge = rooms * nights * 150;
    if (nights >= 7) {
        charge -= charge / 10;
    }
    if (rooms >= 5) {
        charge -= charge / 20;
    }
    return charge;
}
```

If the number of valid nights is 0, it returns 0. Otherwise, it calculates the charge based on the number of rooms and nights. If the number of valid rooms is greater than or equal to 5, it subtracts 20% of the charge from the charge. Finally, it returns the calculated charge.
