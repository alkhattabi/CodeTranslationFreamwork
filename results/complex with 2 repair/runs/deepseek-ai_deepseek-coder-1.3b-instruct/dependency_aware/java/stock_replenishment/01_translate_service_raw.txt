Here is the Java version of your Python code:

```java
public class Service {
    public static int order_quantity(int n) {
        int demand = Utils.weekly_demand(n);
        int safety = 15;
        if (demand < 100) {
            safety = 35;
        }
        int available = n;
        if (n <= 0) {
            available = 0;
        }
        int shortage = demand + safety - available;
        if (shortage <= 0) {
            return 0;
        }
        int packs = (shortage + 11) / 12;
        return packs * 12;
    }
}
```

The Java code is almost identical to the Python code, but there are some differences due to the differences between the two languages. For example, in Java, division of two integers results in an integer, so we need to use the "/" operator for division and the "//" operator for integer division. Also, Java does not have a built-in function to check if a number is negative, so we need to check if "n" is less than 0 before using it.
