Here is the Java version of your Python code:

```java
public class Service {
    public static int yearly_interest(int n) {
        int band = Utils.credit_band(n);
        if (band == 0) {
            return -1;
        }
        int principal = 10000 + (n - 300) * 10;
        int rate = 18 - band * 3;
        int interest = (int) (principal * rate / 100.0);
        if (principal > 14000) {
            interest += 125;
        }
        return interest;
    }
}
```

And here is the Java version of the Utils class:

```java
public class Utils {
    public static int credit_band(int n) {
        if (n < 300 || n > 850) {
            return 0;
        }
        if (n >= 750) {
            return 4;
        }
        if (n >= 650) {
            return 3;
        }
        if (n >= 550) {
            return 2;
        }
        if (n >= 450) {
            return 1;
        }
        return 0;
    }
}
```

Please note that in Java, division of two integers results in an integer. So, the interest calculation is done with a decimal point to maintain the fractional part.
