```java
public class Utils {
    public static int weightBlocks(int n) {
        if (n <= 0) {
            return 0;
        }
        if (n > 10000) {
            n = 10000;
        }
        return (n + 499) / 500;
    }
}

public class Service {
    public static int transportCost(int n) {
        int blocks = Utils.weightBlocks(n);
        if (blocks == 0) {
            return 0;
        }
        int price = 1200 + blocks * 180;
        if (blocks > 5) {
            price += (blocks - 5) * 70;
        }
        if (blocks > 12) {
            price += (blocks - 12) * 90;
        }
        return price;
    }
}

public class Main {
    public static int solve(int n) {
        int blocks = Utils.weightBlocks(n);
        if (blocks == 0) {
            return 0;
        }
        int cost = Service.transportCost(n);
        int fuel = (cost * 8 + 99) / 100;
        int insurance = (blocks >= 10) ? 300 : 100;
        return cost + fuel + insurance;
    }
}
```

Please note that in Java, division operation `/` always returns a floating point number. So, we need to use integer division `/` and multiply by 100 to get the result as an integer.
