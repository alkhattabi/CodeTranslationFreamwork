```java
public class Utils {
    public static int valid_nights(int n) {
        if (n <= 0) {
            return 0;
        }
        int rooms = n / 100;
        int nights = n % 100;
        if (rooms < 1 || rooms > 20 || nights < 1 || nights > 30) {
            return 0;
        }
        return nights;
    }
}
```

Please note that the Java version of the Utils class is in the same package as the Service class, so you can call the `valid_nights` method directly from the Service class.
