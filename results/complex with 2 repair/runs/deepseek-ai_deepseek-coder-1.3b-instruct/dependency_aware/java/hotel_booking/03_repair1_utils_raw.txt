```java
public class Utils {
    public static int valid_nights(int n) {
        if (n <= 0) {
            return 0;
        }
        int rooms = n / 100;
        int nights = n % 100;
        if (rooms < 1 || rooms > 20 || nights < 1 || nights > 30) {
            return 0;
        }
        return nights;
    }
}
```

This Java code declares a public class named Utils with a public static method named valid_nights. The method takes an integer as a parameter and returns an integer. The method first checks if the input number is less than or equal to 0, if so, it returns 0. Then it calculates the number of rooms and nights from the input number. If the number of rooms is less than 1 or greater than 20, or the number of nights is less than 1 or greater than 30, it returns 0. Otherwise, it returns the number of nights.
