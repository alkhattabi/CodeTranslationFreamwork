```javascript
import { order_quantity } from "./service.mjs";
import { weekly_demand } from "./utils.mjs";

export function solve(n) {
    const quantity = order_quantity(n);
    if (quantity === 0) {
        return 0;
    }
    const demand = weekly_demand(n);
    const unit_cost = quantity >= 120 ? 30 : 25;
    const shipping = demand > 100 ? 400 : 200;
    return quantity * unit_cost + shipping;
}
```

This code exports a function solve that takes an integer n as an argument. It uses the imported functions from the service.mjs and utils.mjs modules to calculate the quantity of items to order and the shipping cost. The quantity is calculated based on the demand and the available supply. The unit cost and shipping cost are then calculated and returned as the total cost.
