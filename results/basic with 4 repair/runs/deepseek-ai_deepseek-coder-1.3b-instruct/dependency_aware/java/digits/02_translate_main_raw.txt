Here is the Java version of your Python code:

```java
public class Main {
    public static int solve(int n) {
        int value = Utils.digit_sum(n);
        if (value % 2 == 0) {
            return value + 1;
        }
        return value - 1;
    }

    public static class Utils {
        public static int digit_sum(int n) {
            n = Math.abs(n);
            int total = 0;
            while (n > 0) {
                total += n % 10;
                n /= 10;
            }
            return total;
        }
    }
}
```

This Java code does the same thing as your Python code. It calculates the sum of the digits of a number and then checks if the sum is even. If it is, it adds 1 to the sum, otherwise it subtracts 1. The `Utils` class is a static class in the `Main` class, so it can be called without creating an instance of the `Main` class.
