Here is the JavaScript ES-module source code for the service.mjs file:

```javascript
// utils.mjs
export function digit_sum(n) {
    n = Math.abs(n);
    let total = 0;
    while (n > 0) {
        total += n % 10;
        n = Math.floor(n / 10);
    }
    return total;
}
```

And here is the JavaScript ES-module source code for the service.mjs file:

```javascript
// service.mjs
import { digit_sum } from "./utils.mjs";

export function score_digits(n) {
    return digit_sum(n) * 3;
}
```

Please note that the `score_digits` function in the `service.mjs` file is using the `digit_sum` function from the `utils.mjs` module. This is a cross-file call, as the `digit_sum` function is being used in the `score_digits` function.
