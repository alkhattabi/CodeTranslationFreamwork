```java
public class Service {
    public static int discount(int n) {
        return tier(n) * 5;
    }

    private static int tier(int n) {
        if (n >= 100) {
            return 3;
        }
        if (n >= 50) {
            return 2;
        }
        if (n >= 10) {
            return 1;
        }
        return 0;
    }
}
```

In the original Python code, the method `tier(n)` was not declared as static, which is why it was not found. I added the `static` keyword to the `tier(n)` method in the `Service` class.
