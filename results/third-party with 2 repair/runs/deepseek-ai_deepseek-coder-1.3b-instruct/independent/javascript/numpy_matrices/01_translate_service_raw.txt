Here is the JavaScript equivalent of your Python code:

```javascript
import { vector_signature } from "./utils.js";

export function matrix_energy(n) {
  let x = Math.max(-100, Math.min(100, n));
  let m = [
    [x % 5, 2, -1],
    [3, x % 7, 4],
    [1, 5, x % 3]
  ];
  let square = m.map(row => row.map(x => x * x).reduce((a, b) => a + b, 0));
  let diagonal = square[0];
  return diagonal + vector_signature(n);
}
```

This JavaScript code does the same thing as your Python code. It calculates the energy of a matrix with a given size `n`. The matrix is a 3x3 array, and the energy is calculated as the sum of the diagonal elements of the square matrix and the result of `vector_signature(n)`.

Please note that JavaScript does not have a built-in function to calculate the trace of a matrix, so I used the `map` function to create a new array where each element is the sum of the corresponding elements in the original array.

Also, please note that JavaScript uses `@` for matrix multiplication, not `@` for matrix multiplication in Python.
