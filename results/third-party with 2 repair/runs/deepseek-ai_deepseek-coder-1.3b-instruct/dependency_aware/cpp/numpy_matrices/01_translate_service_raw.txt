Here is the C++ implementation of the Python code. Note that the C++ version of the code uses the same logic as the Python code, but it uses the C++ standard library instead of numpy.

```cpp
#pragma once
#include "api.hpp"
#include <algorithm>
#include <cmath>
#include <vector>

int vector_signature(int n) {
    n = std::max(std::min(n, 100), -100);
    std::vector<int> v = {n % 11, std::abs(n) % 7, (n / 3) % 9};
    std::vector<std::vector<int>> m = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int out = 0;
    for (int i = 0; i < 3; i++) {
        out += m[i % 3][i] * v[i];
    }
    return std::abs(out);
}

int matrix_energy(int n) {
    int x = std::max(std::min(n, 100), -100);
    std::vector<std::vector<int>> m = {{x % 5, 2, -1}, {3, x % 7, 4}, {1, 5, x % 3}};
    int square = 0;
    for (int i = 0; i < m.size(); i++) {
        for (int j = 0; j < m.size(); j++) {
            square += m[i][j] * m[j][i];
        }
    }
    int diagonal = square / m.size();
    return diagonal + vector_signature(n);
}
```

Please note that the `matrix_energy` function is not a perfect translation of the Python code because it uses numpy's matrix multiplication which is not directly supported in C++. The C++ version uses a nested loop to calculate the square of the matrix and then calculates the trace of the square matrix. The `vector_signature` function is also not a perfect translation because it uses numpy's modulo operation which is not directly supported in C++. The C++ version uses a vector to store the modulo results and then calculates the signature using a nested loop.
